# Session resurrection replays JSONL from offset 0

When a session goes idle >10min, pollFiles() removes the file and broadcasts agentClosed. When the user resumes, addFile() creates a new WatchedFile with offset:0 and reads all historical lines. Agent gets a new ID/palette, all historical tool events replay as a burst. Impact: character disappears and reappears with different appearance; stale tool event storm.

## Design

Possible fix: persist file offset per session ID so resurrection resumes from where it left off. Or: on addFile, skip to end of file (set offset = file size) and only process new lines. See pixel-agents-open-items-r2.temp.md bug #1.
