# Path edge refinements

After edge compositing infrastructure is in place (pa-20z7), refine path tile handling. Currently path3 (groundTiles.ts lines 148-165) is a hand-crafted half-grass/half-path west-edge transition sprite included in pathVariants as the 3rd variant. With algorithmic compositing now handling all edge directions, path3 is redundant and doesn't work well for narrow 1-2 tile wide corridors (79% of path tiles have multi-side edges).

This task removes path3, adjusts variant selection, and verifies that path corridors and corners render well with the compositing approach.

## Design

#### Key file: webview-ui/src/village/groundTiles.ts

##### 1. Remove path3

Delete the path3 sprite definition (lines 148-165) and update pathVariants:
```typescript
// Before: const pathVariants: readonly SpriteData[] = [path1, path2, path3]
// After:  const pathVariants: readonly SpriteData[] = [path1, path2]
```

##### 2. Fix variantIndex for paths

variantIndex() (line 505-507) returns 0-2 via ((col * 7 + row * 13) % 3 + 3) % 3. With only 2 path variants, index 2 would be undefined.

Option A: Add a separate variant selector for paths that uses % 2.
Option B: Use pathVariants[idx % pathVariants.length] in selectBaseSprite.
Option C: Keep variantIndex as-is and just index with % 2 for paths specifically.

Recommend Option C — minimal change, other tile types still use 3 variants.

##### 3. Update selectBaseSprite

In the selectBaseSprite function (created by pa-20z7):
```typescript
if (tileType === TileType.PATH) return pathVariants[idx % pathVariants.length]
```

##### 4. Visual verification of path corridors

Key layout patterns to verify (from tileMap.ts LAYOUT_ROWS):
- Vertical corridors (1 tile wide): cols 20-21 around rows 7-12 — grass on both E and W sides
- Horizontal corridors: row 13 cols 7-20 — grass on both N and S sides
- T-junctions and corners: where paths branch
- Path segments adjacent to zones (paths touching gathering, cooking)

All should show graduated grass blending on sides that border non-path tiles.

#### Acceptance criteria

- path3 sprite removed from codebase
- pathVariants has exactly 2 entries (path1, path2)
- No index-out-of-bounds errors
- All path tiles render with appropriate edge blending
- Narrow corridors show grass blending on both sides simultaneously

#### Verification

Build and visually inspect path tiles, especially:
- 1-tile-wide vertical paths (grass blending E+W)
- Horizontal paths (grass blending N+S)
- Path corners and T-junctions
- Wide path areas (blending only on outer edges)
