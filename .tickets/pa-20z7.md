# Edge compositing infrastructure

Add the core infrastructure for algorithmic tile edge blending in groundTiles.ts, then wire it up for all tile types. Currently isZoneEdge() (line 514) returns a boolean and getGroundSprite() (line 541) returns pre-built sprite references directly. This task replaces that with a pre-computed sprite cache where each tile's sprite has dithered edge pixels blended toward its neighbors.

After this task, all tile types should show edge blending — paths blend toward grass on edges, zones blend toward grass (or toward each other), etc. The generic blending works for all cases; subsequent tasks refine specific type pairs.

## Design

#### Key file: webview-ui/src/village/groundTiles.ts

##### 1. Edge detection — replace isZoneEdge (lines 514-522)

Add NSEW bitmask constants and getEdgeFlags():
```typescript
const EDGE_N = 1, EDGE_S = 2, EDGE_E = 4, EDGE_W = 8

function getEdgeFlags(type: TileType, col: number, row: number): number {
  let flags = 0
  if (row <= 0 || tileMap[row-1][col] !== type) flags |= EDGE_N
  if (row >= VILLAGE_ROWS-1 || tileMap[row+1][col] !== type) flags |= EDGE_S
  if (col >= VILLAGE_COLS-1 || tileMap[row][col+1] !== type) flags |= EDGE_E
  if (col <= 0 || tileMap[row][col-1] !== type) flags |= EDGE_W
  return flags
}
```

Add getNeighborType() to look up what type is on each side:
```typescript
function getNeighborType(col: number, row: number, dc: number, dr: number): TileType {
  const nc = col + dc, nr = row + dr
  if (nc < 0 || nc >= VILLAGE_COLS || nr < 0 || nr >= VILLAGE_ROWS) return TileType.VOID
  return tileMap[nr][nc]
}
```

##### 3. blendEdges function

Takes a base sprite, clones it, and dithers neighbor pixels on flagged edges:
```typescript
function blendEdges(base: SpriteData, edges: number, col: number, row: number, tileType: TileType): SpriteData {
  const result = base.map(r => [...r])
  const dirs: Array<[number, number, number, number]> = [] // [flag, dc, dr, axis]
  if (edges & EDGE_N) dirs.push([EDGE_N, 0, -1, 0])
  if (edges & EDGE_S) dirs.push([EDGE_S, 0, 1, 0])
  if (edges & EDGE_E) dirs.push([EDGE_E, 1, 0, 1])
  if (edges & EDGE_W) dirs.push([EDGE_W, -1, 0, 1])

  for (const [_flag, dc, dr, axis] of dirs) {
    const neighborType = getNeighborType(col, row, dc, dr)
    const palette = BLEND_PALETTE[neighborType]
    if (!palette) continue

    // Apply 3-pixel graduated dither
    // For N/S edges: modify rows 0-2 or 13-15
    // For E/W edges: modify cols 0-2 or 13-15
    // Depth 0: ~75% replacement, Depth 1: ~50%, Depth 2: ~25%
    // Use deterministic hash: ((col * 7 + row * 13 + pixelRow * 3 + pixelCol * 5) % N) for which pixels to replace
    // Pick color from palette using hash: palette[hash % palette.length]
  }
  return result
}
```

The dithering depths (0/1/2) correspond to pixel rows/cols from the edge:
- N edge: rows 0, 1, 2
- S edge: rows 15, 14, 13
- E edge: cols 15, 14, 13
- W edge: cols 0, 1, 2

At each depth, the replacement probability determines density:
- Depth 0 (outermost): replace if hash % 4 !== 0 (75%)
- Depth 1: replace if hash % 2 === 0 (50%)
- Depth 2: replace if hash % 4 === 0 (25%)

Only replace non-empty pixels (preserve transparency).

##### 4. Extract selectBaseSprite from getGroundSprite

Move the current sprite selection logic (lines 548-562) into a private selectBaseSprite(tileType, col, row) function. This includes variant selection for grass/path/bamboo, solid fill for zones, landmark placement for woodcutting/cooking.

##### 5. Build sprite cache at module load

```typescript
const spriteCache: SpriteData[][] = []
for (let row = 0; row < VILLAGE_ROWS; row++) {
  spriteCache[row] = []
  for (let col = 0; col < VILLAGE_COLS; col++) {
    const tileType = tileMap[row][col]
    const base = selectBaseSprite(tileType, col, row)
    const edges = getEdgeFlags(tileType, col, row)
    spriteCache[row][col] = edges !== 0 ? blendEdges(base, edges, col, row, tileType) : base
  }
}
```

##### 6. Rewrite getGroundSprite as cache lookup

```typescript
export function getGroundSprite(_tileType: TileType, col: number, row: number): SpriteData {
  return spriteCache[row][col]
}
```

Keep the same export signature for renderer.ts compatibility (renderer.ts:83 is the only consumer).

##### 7. Keep isZoneEdge temporarily

isZoneEdge() is still used by selectBaseSprite for landmark placement (woodcutting/cooking landmarks only placed at non-edge positions). Keep it alongside getEdgeFlags — it can be refactored later.

#### Acceptance criteria

- All tiles render from the sprite cache (no functional change to getGroundSprite API)
- Edge tiles show visible dithered blending toward their neighbors
- Interior tiles (no different neighbors) render identically to before
- Woodcutting stumps and cooking fire pits still appear at correct positions
- No runtime errors or visual regressions
- App loads without perceptible delay from cache computation

- Interior tiles unchanged
